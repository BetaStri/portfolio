# Портфолио — Лада Большакова

Статическая страница. Публикуется через GitHub Pages.

## Как опубликовать

1. Имя репозитория должно быть ровно `вашлогин.github.io`
   (например `ladabolshakova.github.io`), видимость — **Public**.
2. `index.html` и папка `img` лежат в **корне** репозитория, не во вложенной папке.
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
   ветка `main`, папка `/ (root)` → Save.
4. Через 1–10 минут адрес появится там же, на странице Pages.

## Как обновить

Открыть нужный файл на GitHub → карандаш (Edit) → поправить → Commit changes.
Сайт обновится за минуту.

## Что внутри

- `index.html` — вся страница: разметка и стили в одном файле
- `img/` — работы, пережаты под веб (вся папка ~1,2 МБ)
- `.nojekyll` — отключает лишнюю обработку на стороне GitHub
